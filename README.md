# Wageet employer portal

Workplace portal for organization details, the payroll cycle, the access policy, employee invitations, confirmed work records, and payday funding.

## Stack

- Next.js 16 (App Router) and React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui (Base Nova), themed with the Wageet forest and orange palette
- Outfit, matching the public site

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Sign-in is at [/sign-in](http://localhost:3000/sign-in) and is not connected to an account system yet.

Add more shadcn components with:

```bash
npx shadcn@latest add <component>
```
